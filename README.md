# yvr-cherry-blossoms


Data from the Vancouver Open Data portal, [Public Trees](https://opendata.vancouver.ca/explore/dataset/public-trees/information/?disjunctive.common_name&disjunctive.species_name) dataset.

## Setup

```r
install.packages(c("arrow", "sf", "leaflet", "dplyr"))
install.packages('spopt', repos = c('https://walkerke.r-universe.dev', 'https://cloud.r-project.org'))
```
